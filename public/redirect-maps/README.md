## What are these files for?

These files map ids from the old site/DB to the new site/DB. Essentially, they are used to redirect urls that exist in search engines and other webpages to the new site urls, eliminating as many 404s as possible.

## When can these files go away?

Not sure. They'll probably need to stay for awhile, but eventually google will re-write most of the links so that we can remove this bloat.
